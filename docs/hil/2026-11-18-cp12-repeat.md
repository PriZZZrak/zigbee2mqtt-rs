## Limits

- Startup is measured from the binary's own log lines (first line to
  `Zigbee2MQTT started!`); the MQTT/HTTP latencies are upper bounds.
- The data copy has no converter database (R1): devices remain definition-less,
  so incoming reports are logged but do not repopulate the state cache; the
  state file therefore stayed byte-identical.
- Home Assistant discovery was disabled on the copy to avoid adding retained
  topics to the live broker.
- Reboot with the packaged service was not repeated (Node occupies the overlay);
  the 2026-11-17 packaged reboot evidence remains the reference. This run does
  not claim a new reboot result.
