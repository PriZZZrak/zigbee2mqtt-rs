### Configuration and storage — CONFIG-003/004, STORAGE-002/003

- App `lib/util/settings.ts:206–263` (`write`), `332–445` (`read`),
  `447–507` (`getPersistedSettings/get/set/apply`), `562–700` (entity mutation).
  `test/settings.test.ts` and `test/settingsMigration.test.ts` provide reference
  cases for loading, defaults, mutation and migrations; inspect their complete
  fixtures before implementation. App bridge rename/options → settings mutation
  → full persisted configuration, including external files/secrets/env precedence.
- Herdsman `src/controller/database.ts:1–130` (`open/insert/update/remove/write`),
  `src/controller/model/device.ts` and `endpoint.ts` serialization, `group.ts`
  identity/persistence. Controller tests supply database/device/group fixtures.
  Device/endpoint/group objects → database records → NDJSON → restart import.
- Rust `src/config.rs:Config::save` serializes limited typed structs, dropping
  unknown configuration; local `username` does not implement upstream `mqtt.user`.
  `src/database.rs:sync_groups` removes Group entries before looking up previous
  IDs. Newly synced devices without assigned `database_id` can allocate new IDs
  repeatedly. Endpoint lists and software-build metadata need preservation.
- Required negatives: duplicate/unknown records, existing ID reuse, repeated sync,
  unknown YAML keys, external files, failure during atomic write, ENOSPC, shutdown
  while dirty and original → Rust → original reopen. No round-trip guarantee
  follows from parser unit tests. See plan 03 and R1-01..06/36.

### Z-Stack — ADAPTER-004/005, existing ADAPTER/ZIGBEE rows

- Herdsman `src/adapter/z-stack/adapter/manager.ts:55–289`
  (`start/determineStrategy`) and restore/commissioning methods from line 301;
  `zStackAdapter.ts` startup/sendZclFrameToEndpoint/waitFor and ZNP transport.
  `test/adapter/z-stack/adapter.test.ts` and manager tests exercise startup,
  version-dependent paths, confirmations, waiters and recovery with mocks.
- Path: app Zigbee start → herdsman controller/adapter → manager inspection of
  configuration, NIB, NV and backup → startup/restore/commission → coordinator

  CC2531 product-ID predicates. Do not apply legacy skips to every Dongle-P.
- **HARDWARE_REQUIRED:** Dongle-P startup/restart/join/report/set/get/reconnect and
  persistence for R1; both Dongle-P and CC2531 for complete Stage 1. No HIL ran.
  New latest frame-type matching fix is tracked separately from the baseline.

### Generic converter pipeline — CONVERTER-007..012

- Converters `src/indexer.ts`; `src/index.ts:139–150` normalization,
  `217–245` index loading, `420–502` preparation, `504–603` selection/whiteLabel,
  `605+` fingerprint matching; `src/lib/{types,modernExtend,store,utils}.ts` and
  `src/devices/lytko.ts`. Inspected index test cases in `test/index.test.ts`;
  further real-package fz/tz/modernExtend/tuya tests remain per-feature work.
- App `lib/extension/receive.ts:102–190`: message → matching fz → await converter
  → publish callback/result/postprocess → application state/MQTT. App
  `publish.ts:110–289`: MQTT get/set → keys/endpoints/converter selection →
  convertGet/convertSet → Zigbee effects → conditional optimistic publication.

  `test/extensions/{receive,publish,configure,onEvent}.test.ts`.

  standard cluster already returned native state. Generic definition authority
  and native acceleration need a source-backed arbitration ADR; no deletion of
  existing handlers is approved.
- `.github/workflows/convert-converters.yml:117–120` flattens device modules and
  combines helpers under `lib/`; runtime asks for `devices/<vendor>.js`.
  Compilation/publication succeeds independently of runtime layout/host support.
- Required fixtures include modelID != product model, null bucket, priorities,
  fingerprint/whiteLabel/regex, real modernExtend, Promise/timer state across

  using the same pipeline. Synthetic CJS unit tests do not cover these.

  domain side effect → event/state/storage → response. Returning `ok` without

  and discovery cleanup need app `homeassistant.ts`/tests and real publication
