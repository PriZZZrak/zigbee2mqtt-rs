## What is still provisional

- **Inventory completeness is unknown.** No audited-domain fraction, baseline
  catalog total or per-converter denominator has been established yet, so no
  percentage here can be read as “complete compatibility”.
- **Scenario counters are unverified.** All legacy verified-case counts were
  reset; historical `total_cases` remain as work estimates and contribute only to
  the denominator until cases are enumerated and re-tested. Broad legacy rows
  still need decomposition into independently testable behavior.
- **R1 is separate.** The first release targets Routerich AX3000 / OpenWrt 24.10.8
  with a Dongle-P and a fixed personal device set. It has its own
  [acceptance matrix](../../.opencode/plan/10-acceptance-matrix.md) and does not
  equal complete Stage 1 or global parity.
- **Hardware evidence is absent.** No coordinator or device HIL was run for this
  report; mock/simulated evidence cannot promote a hardware row to `VERIFIED`.
- **Reference execution is limited.** Node, mosquitto, browser and OpenWrt
  tooling were unavailable in the audit environment. Only the Rust checks listed
  in the generated section were executed.
- **Upstream drift is tracked, not merged.** `DRIFT_DETECTED` means newer upstream
  commits exist. The pinned baseline is intentionally unchanged until a reviewed
  advancement; the queue is in [upstream-changes.md](upstream-changes.md).

## Reproduce

```bash
python3 scripts/parity_report.py            # print the dashboard text
python3 scripts/parity_report.py --check    # validate + fail if README is stale
python3 scripts/parity_report.py --write    # regenerate the marked region
python3 -m unittest discover -s scripts/tests -v
```
